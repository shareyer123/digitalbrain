# System Wiki — index

This is the SYSTEM tier, shared by every project. DigitalBrain owns it because DigitalBrain *is* the
working environment. Project-specific knowledge belongs in that project's own `Context/wiki/`, never here.

**`/start` reads this index only.** Fetch a page on demand — do not read the folder.

| Page | What it answers |
|---|---|
| [[Verification]] | **How checks lie.** Green because it measures the wrong thing; red for a reason unrelated to the data. |

Add a row here for every fact that ages — a port, a version, a count — and name on the page how it
gets re-checked. **A fact with no owner is a fact that will be wrong and still be trusted.**

## Rules for this wiki

- **A page here must be true for more than one project.** Otherwise it belongs in that project's wiki.
- **Nothing that ages without an owner.**
- **There is no `Lessons.md`.** Durable lessons are pages here.
