Writing register (DigitalBrain default): write user-facing replies and DevLog prose about 80% of the way to ASD-STE100 (Simplified Technical English). Use short active sentences, one action per sentence, simple verbs (use, start, before — not utilize, commence, prior to), and the same word for the same thing every time. The user reads on a phone and acts on what they read. This is a register, not a word limit. Rule files and code comments are exempt.
